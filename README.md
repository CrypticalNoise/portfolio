# Nuubzzz Portfolio

A simple image-first Roblox 3D art portfolio designed for GitHub Pages.

## Replace the demo work
Put your renders/screenshots in `assets/projects/` and change the `<img src="...">` paths in `index.html`.
The included SVGs are only visual placeholders so the site looks complete before you add your own work.

## Personalise
- Change `nuubzzz` in `index.html` to your preferred name/brand.
- Replace `your@email.com` with your contact email.
- Edit project titles, categories and descriptions.
- Add/remove project cards as needed.
- Update the social links if you want them in the header/footer.

## GitHub Pages
Upload the contents of this folder to a GitHub repository. Then go to:
Settings → Pages → Deploy from a branch → select `main` and `/root`.
